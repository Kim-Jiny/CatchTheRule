# 탭바 + 타임어택(도전) 탭 + 설정 탭 리뉴얼 명세 — 네온 게임 느낌

`docs/home-ui-spec.md` 의 네온 스타일(모드색 토큰, 네온 배경, 카드/링/바/샤인 버튼/스태거/눌림/카운트업 컴포넌트)을 **그대로 재사용**한다. 이미 구현된 컴포넌트(iOS `DesignSystem/Neon.swift`·`NeonBackground.swift`, Android `ui/home/NeonKit.kt`·`ui/theme/NeonBackground.kt`·`HomeHero.kt`)를 가져다 쓰고, 부족한 것만 추가한다.
게임 플레이 화면(캠페인 세션, `TimeAttackView`/`TimeAttackScreen` 의 문제 푸는 화면)은 **건드리지 않는다** — 이 명세는 탭바, 도전 탭(`ChallengeView`/`ChallengeScreen`), 설정 탭(`SettingsView`/`SettingsScreen`)만 다룬다. 기존 기능·문자열·네비게이션 유지(UI 레이어 교체).

## 1. 탭바 디자인 (공통)
- 시스템 탭바/Material NavigationBar 를 **커스텀 "플로팅 네온 탭바"** 로 교체.
- 모양: 화면 하단에서 12pt 띄운 **캡슐**(높이 ≈ 64, 좌우 마진 16), 배경은 `#10141C` 불투명도 0.92 + 1pt 외곽선(흰색 0.08) + 아래쪽 은은한 그림자. 하단 세이프에어리어(홈 인디케이터/제스처 바)를 존중해 그 위에 띄운다.
- 항목 3개(홈·도전·설정): 선택된 항목은 **알약(pill) 하이라이트**(액센트 그라데이션 `Theme.accent→accent2`, 은은한 글로우)가 부드럽게 슬라이드(`matchedGeometry`/animateDpAsState, 스프링)하며 이동하고, 선택 항목만 **아이콘 + 라벨**을 보여 폭이 늘어난다(라벨은 페이드/슬라이드 인). 비선택은 아이콘만(흰색 0.45). 아이콘은 선택 시 살짝 커졌다 돌아오는 바운스(스케일 1→1.18→1.0).
- 탭 전환 시 가벼운 햅틱(`hapticsOn` 존중), 콘텐츠는 짧은 페이드+약간의 Y 슬라이드로 전환(상태 보존 필수 — 탭을 바꿔도 홈/도전/설정의 스크롤·네비게이션 상태가 유지되어야 함).
- 플로팅이라 각 탭 콘텐츠 하단에 **탭바 높이만큼 여유 패딩**을 줘서 마지막 항목/배너가 가려지지 않게(`safeAreaInset`/`contentPadding`). 배너 광고는 기존 위치(각 화면 안)를 유지하되 탭바와 겹치지 않게.
- 접근성: 각 항목에 라벨/트레이트(선택됨) 부여. Reduce Motion 이면 슬라이드/바운스 없이 즉시 전환.
- 구현 힌트: iOS 는 `TabView` 를 유지하되 `.toolbar(.hidden, for: .tabBar)` 로 시스템 바를 숨기고(selection 바인딩 사용) 그 위에 커스텀 바를 `overlay(alignment: .bottom)` 로 얹는 방식이 상태 보존에 안전. Android 는 `Scaffold` 의 `NavigationBar` 를 커스텀 composable 로 교체하고 `saveable`/`rememberSaveable`/`key` 로 각 탭 상태를 보존.

## 2. 도전(타임어택) 탭
현재: 제목 + 최고기록 카드(⚡ + 시작 버튼) + 배너 + 리더보드 리스트(단조). 목표: 경쟁 느낌이 나는 네온 화면.
- 배경은 `ScreenBackground(animated: true)`(네온 배경). 헤더: "도전" 타이틀(그라데이션 텍스트) + 부제 + 오른쪽 트로피 아이콘(은은한 글로우 펄스).
- **내 최고기록 히어로 카드**: 큰 카드(모드 색 대신 도전 전용 색 **#FFB020 → #FF5C8A** 그라데이션 테마), 번개 아이콘 글로우 애니메이션, 최고 점수를 **카운트업** 큰 숫자로, "시작" 버튼은 샤인 스윕 + 펄스 글로우 `ShineButton` 스타일(`challenge_start`). 안내 문구(`challenge_mode_note`)는 작은 칩으로.
- **리더보드**: 상위 3명은 **포디움 카드**(1위 가운데 크게 왕관, 2·3위 양옆; 금 #FFD166 / 은 #C0C8D8 / 동 #FF9F6B 네온 테두리·글로우, 닉네임·점수·국가 표시는 기존 데이터 그대로), 4위 이하는 리스트 행(순위 번호 칩 + 닉네임 + 점수), **내 항목은 액센트 테두리로 강조**(기존에 내 기록 식별 로직이 있으면 사용, 없으면 닉네임/기기 기준 기존 방식 유지). 데이터가 3명 미만이면 있는 만큼만.
- 로딩은 스피너 대신 **스켈레톤 시머**(회색 카드 위로 지나가는 빛), 빈 상태/오류 상태는 아이콘+문구 카드(기존 문구 재사용).
- 입장 스태거 애니메이션, 순위 숫자/점수 카운트업(처음 한 번), 눌림 효과.

## 3. 설정 탭
현재: 일반적인 설정 리스트. 목표: 그룹 카드 + 컬러 아이콘 칩 + 네온 토글로 "게임 앱다운" 설정 화면.
- 배경은 네온 배경(animated: true). 상단에 **프로필 카드**: 큰 아바타 원(닉네임 첫 글자 또는 기본 아이콘, 액센트 그라데이션 링), 닉네임(없으면 기존 문구), 별 합계(`home_total_stars` 카운트업), 푼 문제 수 등 이미 계산 가능한 값(새 로직 최소화). 닉네임 편집은 기존 방식 유지.
- 기존 섹션(소리/햅틱 토글, 닉네임, 힌트 구매/광고제거, 약관·개인정보, 문의하기, 앱 정보/버전/업데이트 안내, 진행도 초기화 등 **현재 있는 항목 전부**)을 **둥근 그룹 카드**로 묶고, 각 행 왼쪽에 **컬러 아이콘 칩**(항목 성격별 네온색: 소리=시안, 햅틱=보라, 힌트/상점=앰버, 약관/정책=회색 블루, 문의=그린, 정보=핑크, 위험(초기화)=빨강)을 둔다. 행 구분선은 얇고 은은하게, 그룹 헤더는 작은 캡션(모드색).
- 토글은 액센트(시안-보라 그라데이션) 켜짐 상태가 눈에 띄게(커스텀 스타일; iOS `Toggle` 은 `.tint`, Android `Switch` colors 로 처리, 너무 큰 커스텀은 지양).
- 위험 동작(진행도 초기화 등)은 기존 확인 다이얼로그 유지, 눌림 효과 추가.
- 입장 스태거 애니메이션(카드 단위), 앱 정보 카드에 버전 칩 + 업데이트 가능 시 네온 배지(기존 업데이트 안내 로직 사용).
- 문의하기 화면(`InquiryView`/`InquiryScreen`)은 상위 스타일(배경/카드/버튼)만 맞추고 폼 동작은 그대로.

## 4. 문자열/데이터
- 기존 키 재사용. 더 필요하면 **만들지 말고 보고**(gen_l10n.py 단일 소스; `Localizable.xcstrings`·`res/values*/strings.xml` 직접 편집 금지). 이미 있는 키: `tab_home`, `tab_challenge`, `tab_settings`, `challenge_*`, `ranking`, `home_total_stars` 등.
- 새 저장 데이터 없음(필요 시 기존 `ProgressStore` 값만 읽기).

## 5. 성능·접근성
- 60fps, 무한 애니메이션은 화면이 보일 때만, Reduce Motion 존중(홈 명세 §8 동일). 포디움·리스트는 항목 수가 적으니 일반 컴포저블/뷰로 충분.
- 작은 화면 대응(텍스트 2줄/축소), 소형 안드로이드/iPhone SE 에서 3항목 탭바 라벨이 잘리지 않게.
