# 홈 UI 리뉴얼 명세 — "네온 게임 느낌" (홈 + 챕터 목록)

iOS(SwiftUI)와 Android(Compose)가 **같은 디자인**이 되도록 정의한 단일 명세. 게임플레이 화면은 건드리지 않는다.
대상: 홈 허브(모드 선택), 모드 상세 = 챕터 목록 화면(`CampaignTrackView`/`ModeDetailView`, Android 동등 화면), 공통 배경.
기존 기능/해금 로직/문자열/네비게이션은 그대로 유지한다(UI 레이어만 교체). 현재 느낌: 다크 배경 + 동일한 보라-청록 카드가 세로 리스트 → 너무 단조로움.

## 1. 디자인 토큰
- 배경 베이스 `#0B0E14` → 아래쪽 `#10141C`(세로 그라데이션). 기존 `Theme.bg/bgElevated/card/stroke/textXxx` 는 유지하고 필요한 토큰만 추가.
- **모드별 네온 포인트 컬러** (한 곳에 모아 정의: iOS `Theme.modeColor(track)`, Android `modeColor(track)`):
  numbers `#7C5CFF`(바이올렛) · shapes `#18C8FF`(시안) · logic `#FFB020`(앰버) · contradiction `#FF5C8A`(핑크) · target `#3DDC97`(그린) · match `#FF7A45`(오렌지)
  각 모드에서 파생: `glow = color.opacity(0.55)`, `tint = color.opacity(0.14)`, 그라데이션 `color → color를 보라 쪽으로 15% 섞은 색`.
- 모서리 radius: 카드 22, 칩/버튼 14~16. 외곽선: 1pt, 모드색 `opacity 0.35`(눌렀을 때/현재 항목은 0.9). 카드 안쪽 은은한 모드색 틴트 그라데이션(좌상단→우하단), 모드색 그림자(glow, blur 16~20, opacity 0.25~0.35).
- 타이포: 제목은 굵게(heavy/ExtraBold), 숫자(%, 별)는 monospaced digit. 앱 타이틀은 흰색→시안 그라데이션 텍스트.

## 2. 공통 배경 (`ScreenBackground` / Android 대응) — 살아 있는 배경
- 천천히 떠다니는 **오로라 블롭 3개**(블러된 큰 원: 바이올렛/시안/핑크, opacity 0.12~0.2, 20~30초 주기로 천천히 이동).
- **떠다니는 수학·도형 글리프** 14~18개(`+ − × ÷ = % 7 9 ▲ ● ■ ∑ π ?` 등, opacity 0.04~0.10, 크기 18~44, 아래→위로 천천히 상승하며 회전, 화면 밖으로 나가면 아래에서 재등장). Canvas/TimelineView(iOS) · Canvas+withFrameNanos 또는 infiniteTransition(Android)로 **한 번에 그려** 가볍게(개별 뷰 수십 개 금지).
- **Reduce Motion / 애니메이션 비활성 설정 시** 정적 배경(블롭 고정, 글리프 정지)으로 대체. 화면이 보이지 않을 때(백그라운드/다른 탭)는 애니메이션 중지.
- 배경은 전 화면 공통(홈, 챕터 목록 등 기존 `ScreenBackground` 사용처)이지만 **플레이 화면은 기존 정적 배경 유지**(성능·집중). 배경 컴포넌트에 `animated: Bool` 파라미터를 두고 홈/챕터 목록만 true.

## 3. 홈 화면 레이아웃
위에서 아래로:
1. **헤더**: 앱 타이틀(그라데이션 텍스트, 등장 시 위에서 페이드+슬라이드) + 오른쪽 **별 합계 칩**(⭐ + `home_total_stars` 카운트업 애니메이션 0→값 700ms). 부제는 기존 `home_subtitle`.
2. **이어하기 히어로 카드** (가로 꽉 차는 큰 카드, 높이 ≈ 190):
   - 마지막으로 플레이한 모드(없으면 첫 번째 모드). 라벨 `home_last_played`(작은 캡션, 모드색), 모드 제목(크게), `chapter_label + stage_label` 로 "다음에 풀 위치" 표시(`PuzzleStore.position` 등 기존 로직 재사용), 좌측 큰 글로우 아이콘, 우측 **진행률 링**(두께 8, 모드색 그라데이션, 0→값 애니메이션 900ms ease-out, 가운데 % 카운트업).
   - 하단 **`home_continue` 버튼**: 모드색 그라데이션 pill, 은은한 펄스 글로우(2초 주기) + **샤인 스윕**(빛 줄기가 3초마다 좌→우로 지나감). 탭하면 해당 모드의 이어하기(기존 `continue` 동작과 동일).
   - 카드 탭 = 모드 상세(챕터 목록)로 이동, 버튼 탭 = 바로 이어서 플레이(기존 동작 중 해당하는 것으로 연결; 불가하면 둘 다 모드 상세).
   - 전체 완료한 모드면 히어로는 가장 진행이 덜 된 모드를 보여 준다.
3. **모드 그리드**: 2열, 간격 14, 모드 개수 홀수면 마지막 카드는 한 칸 차지(왼쪽 정렬 또는 가로 꽉). 각 카드(높이 ≈ 150):
   - 좌상단 **글로우 아이콘 타일**(모드색 그라데이션 라운드 사각, 아이콘은 모드마다 **고유 idle 애니메이션**: numbers=# 위아래 살짝 부유, shapes=천천히 회전, logic=전구 글로우 깜빡임, contradiction=삼각형 좌우 흔들림(주기적), target=계산기 펄스, match=불꽃 일렁임/스케일 펄스 — 아이콘마다 반복 주기 다르게 해 동시에 움직이지 않게).
   - 모드 제목(2줄 허용), 하단에 얇은 **진행 바**(모드색, 0→값 애니메이션) + `NN%` 와 "푼 문제/전체" 작은 텍스트.
   - 완료(100%) 모드는 우상단 체크/왕관 배지 + 테두리 글로우 강화.
   - **잠긴 모드**(기존 해금 게이트 전): 어둡게 + 자물쇠 아이콘, 모드색 대신 회색, 은은한 샤인은 없음. 기존 `LockedHome`/잠금 로직 그대로 두고 스타일만 맞춘다(잠긴 카드가 존재하지 않는 구조라면 만들지 말 것).
4. 하단 배너 광고/탭바 위치와 겹치지 않게 스크롤 컨테이너 안에 콘텐츠를 두고 아래 여백 확보.

## 4. 애니메이션/인터랙션
- **입장**: 홈이 처음 보일 때 헤더 → 히어로 → 그리드 카드 순서로 **스태거 등장**(각 +60ms, translateY 24→0, opacity 0→1, 스프링). 탭 전환으로 돌아올 때도 가볍게 재생(과하면 한 번만).
- **프레스**: 모든 카드/버튼 눌림 시 scale 0.96 스프링 + 가벼운 햅틱(기존 `progress.hapticsOn` 준수), 놓으면 복귀.
- **진행률/숫자**: 링·바·퍼센트·별 합계는 보일 때 0→값 카운트업(재방문 시 다시 재생해도 좋으나 짧게).
- 아이콘 idle 애니메이션은 화면이 보일 때만, Reduce Motion 이면 정지.
- 모드 카드 → 챕터 목록 전환은 기본 네비게이션 전환 유지(가능하면 모드색 페이드 오버레이 정도의 가벼운 연출, matchedGeometry/공유 요소 전환은 선택).

## 5. 챕터 목록 화면 (모드 상세)
- 상단 헤더에 해당 **모드색 글로우**(상단 블러 컬러 + 큰 아이콘 워터마크), 제목은 `modeTitle`.
- **이어하기 카드**(기존 `continueCard`)는 히어로와 같은 스타일(모드색 링 + 샤인 버튼)로.
- **챕터 목록은 "경로(타임라인)" 형태**: 왼쪽에 세로 연결선, 챕터마다 원형 노드 —
  완료 = 모드색으로 채워진 체크 노드 + 은은한 글로우, **현재 챕터 = 펄스 링(1.6초 주기)**, 잠김 = 흐린 자물쇠 노드. 연결선은 완료 구간만 모드색 그라데이션, 나머지는 `stroke`.
  챕터 행 카드: 챕터 번호/난이도 제목(`chapterTitle`), 별 합계(`StarRow` 스타일 유지 가능), 얇은 진행 바(0→값 애니메이션).
- 챕터 탭 → 스테이지 목록 펼침 시 **스태거 등장**(각 +40ms)과 높이 애니메이션. 스테이지 칩: 완료 = 모드색 채움+별, 현재 = 펄스 테두리, 잠김 = 흐림. 기존 탭 동작(스테이지 선택 시 시작 인덱스로 플레이) 유지.
- 잠긴 챕터 탭은 기존처럼 무시/가벼운 흔들림.

## 6. 새로 필요한 데이터(앱 로직)
- **마지막으로 플레이한 모드**(`lastPlayedTrack`) 저장: iOS `ProgressStore`(UserDefaults), Android `ProgressStore`(SharedPreferences `ctr_progress`, 키 `lastTrack`). 캠페인 세션이 시작되거나 퍼즐을 맞힐 때(`recordCampaignClear`) 갱신. 값이 없으면 첫 번째 모드(기본 numbers).
- 모드별 "푼 문제 수/전체"는 기존 진행도 계산(퍼센트 계산 로직)에서 파생. 별 합계는 `earnedStars`.

## 7. 문자열
이미 추가됨(gen_l10n.py 단일 소스, 직접 편집 금지): `home_last_played`, `home_total_stars`(%d). 기존 키 재사용: `home_continue`, `chapter_label`, `stage_label`, `mode_*`, `*_chapter_N`. 더 필요한 키가 있으면 **만들지 말고 보고**.

## 8. 성능·접근성
- 60fps 목표: 배경은 Canvas 단일 레이어, 큰 블러는 정적 비트맵/한 번만(프레임마다 새 블러 금지), 리스트/그리드 항목의 무한 애니메이션은 화면에 보일 때만.
- Reduce Motion(iOS `accessibilityReduceMotion`, Android `Settings.Global.ANIMATOR_DURATION_SCALE==0`) 시 무한/장식 애니메이션 생략, 카운트업은 즉시 값.
- 다크 UI 대비 유지(텍스트 흰색/60%).
- 작은 화면(iPhone SE/소형 안드)에서도 2열 카드 텍스트가 잘리지 않게(2줄 + minimumScaleFactor/autoSize).
